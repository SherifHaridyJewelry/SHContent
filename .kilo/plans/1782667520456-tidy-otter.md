# Plan: Cyclic Style Refinement via Distillation

## Problem

Style references (`style_references` in templates) and text-generated scene plates produce bad results:

1. **`style_references`** are raw inspiration images containing other products — they contaminate generation output.
2. **Text-generated scene plates** (via `ScenePlateGenerator` in the app, backed by `workflows/scene_plate_jewelry.json`) look bad and don't carry real output fidelity.
3. The web app's "Scene ref" button (Catalog page line 573) naively adds a generated output image **with product still in it** as a scene reference, worsening future generations.

## Goal

Replace the broken reference system with a **cyclic distillation pipeline**:

```
Creative generation (no ref) → Good outputs → Distill (remove product) → Clean scene refs → Better future generations → repeat
```

Add `DistillSceneRefRequest`:

class DistillSceneRefRequest(BaseModel):
    output_path: str   # e.g., "images/jewelry/catalog_ring01_4x5_abc.jpg"

#### 3. New Service Methods (`app/services/scene_plate_service.py`)
Add to existing service:
- `start_distillation(template_name, output_path, scene_key)` — creates a `ScenePlateJob`, spawns background thread
- `_run_distill_job(job_id, ...)` — coordinates: load template → build distill prompt → KIE API call → download → R2 upload → register on `scene_references`
- `_distill_one(output_path, template_name, scene_key)` — the core logic:

```python
def _distill_one(output_path, template_name, scene_key, api_key, s3, r2_config):
    template = template_service.load_template_dict(template_name)
    
    # Resolve R2 URL for the output image (check catalog lookup or upload if needed)
    r2_source_url = _resolve_or_upload_r2_url(output_path, template_name)

    prompt_payload = {
        "prompt": (
            f"Remove the {scene_key} jewelry product completely from this photograph. "
            f"Preserve EXACTLY: the display surface texture and color, background gradient "
            f"and bokeh blur, lighting direction and shadow placement, depth of field, "
            f"reflections on the surface, and overall color grading. Inpaint the area where "
            f"the product was removed seamlessly — extend the surface material and match "
            f"the lighting so the transition is invisible. The result is a clean, product-free "
            f"studio photography setup. Ultra-realistic, same resolution, same aspect ratio. "
            f"Do not change anything except removing the product."
        ),
        "negative_prompt": (
            f"{scene_key}, jewelry, gemstone, diamond, gold, silver, metal, product, "
            f"new product, different background, replaced surface, changed lighting, "
            f"altered shadows, cartoon, illustration, 3D render, CGI"
        ),
        "image_input": [r2_source_url],
        "api_parameters": template.get("api_parameters", {
            "aspect_ratio": "4:5", "resolution": "2K", "output_format": "jpg"
        }),
    }

    task_id = create_task(api_key, prompt_payload, MockArgs())
    data = poll_task(api_key, task_id)
    
    output_name = f"distilled_{Path(output_path).stem}"
    output_path_local = PROJECT_ROOT / "images" / "jewelry" / f"{output_name}.jpg"
    download_image(data, output_path_local)

    object_key = f"references/distilled/{template_name}/{output_path_local.name}"
    r2_url = upload_file_with_key(s3, r2_config, output_path_local, object_key)

    template_service.add_scene_references(
        template_name, product_type=scene_key, urls=[r2_url]
    )
    return {"id": f"distill_{scene_key}", "status": "success", ...}
```

#### 6. Catalog Service Enhancement (`app/services/catalog_service.py`)
The `_is_scene_plate_path` function (line 96-97) currently only detects files starting with `scene_plate_`. Add detection for distilled files too:
```python
def _is_scene_plate_path(path: str) -> bool:
    stem = Path(path).stem
    return stem.startswith("scene_plate_") or stem.startswith("distilled_")
```

This ensures distilled plates show up correctly in the catalog with the "scene plate" badge and `is_scene_plate` flag.

Replace the naive "Scene ref" link (currently lines 570–593) with:

```tsx
{/* "Distill to Scene Ref" button shown on outputs with a product_id */}
{!item.is_scene_plate && item.product_id && (
  <div style={{ marginTop: "0.5rem" }}>
    <select
      value={distillSceneKey}
      onChange={(e) => setDistillSceneKey(e.target.value)}
      style={{ fontSize: "0.75rem" }}
    >
      <option value="">Distill to scene ref...</option>
      <option value="ring">As ring ref</option>
      <option value="bracelet">As bracelet ref</option>
      <option value="necklace">As necklace ref</option>
      <option value="earrings">As earrings ref</option>
      <option value="default">As general ref</option>
    </select>
    <button
      className="btn btn-secondary"
      disabled={!distillSceneKey || distilling}
      onClick={() => startDistill(item, distillSceneKey)}
    >
      {distilling ? "Distilling..." : "Go"}
    </button>
    {distillJobId && <Link to={`/tasks/scene-plate/${distillJobId}`}>View job</Link>}
  </div>
)}
```
